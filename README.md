# europeism.com

Europeism: «un palimpsesto en 19 borradores». HTML, CSS y JavaScript estáticos, publicados gratis con GitHub Pages.

- `index.html`: todos los textos (los 18 borradores, la palabra, las doce tesis y el borrador 19).
- `styles.css`: el diseño.
- `stage.js`: el mapa que se reescribe al hacer scroll (las fronteras de cada borrador están en la lista `D`, en longitud y latitud, aproximadas), la palabra que pierde el «an», el círculo de las doce estrellas y el mapa donde el visitante dibuja el borrador 19.
- `CONCEPT.md`: el concepto y la narrativa, en español.

Para cambiar un texto: abre `index.html` en GitHub, pulsa el lápiz, edita y pulsa **Commit changes**.
