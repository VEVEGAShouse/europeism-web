# europeism.com

Landing de Europeism. HTML, CSS y JavaScript estáticos, publicados gratis con GitHub Pages.

- `index.html`: todos los textos.
- `styles.css`: el diseño.
- `map.js`: el mapa de puntos de Eurasia con la frontera que se mueve. Carga los datos del mapa desde jsDelivr (world-atlas, de uso libre).
- `page.js`: las estrellas de las tesis, el reloj y «Europe is…».
- `CONCEPT.md`: el concepto y la narrativa, en español.

Para cambiar un texto: abre `index.html` en GitHub, pulsa el lápiz, edita y pulsa **Commit changes**.
